# EVOLECT

A platform connecting event organizers with reliable volunteers — making it easier to find the right volunteer, manage teams, and create better events.

## Features

- **Animated Hero Section** — WebGL liquid glass refraction, gradient text, parallax effects
- **Noise Abstract Background** — Perlin noise procedural animation
- **Responsive Design** — Mobile-first with Tailwind CSS
- **Framer Motion** — Smooth scroll animations and transitions
- **Email Collection** — Early access waitlist form

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS v4
- Framer Motion
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Push to GitHub and enable GitHub Pages in repository settings.
